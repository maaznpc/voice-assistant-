# Contributing

Use JDK 17+, Android SDK 35 and `./gradlew assembleDebug testDebugUnitTest lintDebug`.
Keep the original MIT attribution. New tools must validate arguments and accurately distinguish opening a composer from completing an action.
Do not commit API keys, recordings, signing keys, downloaded models or device data.
Document hardware/provider tests separately from Robolectric tests. See docs/EVALUATION.md.
